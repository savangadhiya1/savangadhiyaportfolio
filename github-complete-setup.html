🚀 Quick Setup Steps

Step 1:
Create All Repositories
Click the "Create Repo" buttons above to create all 8 repositories with the exact names:
blog-website
library-management
task-manager
weather-app
inventory-system
sales-prediction
customer-segmentation
sentiment-analysis
Step 2:
Enable GitHub Pages
For each repository:
  1. Go to repository Settings → Pages
  2. Select "Deploy from a branch"
  3. Choose "main" branch and "/ (root)" folder
  4. Click "Save" and wait 2-3 minutes
Step 3:
Upload Demo Files
For web projects (blog-website, library-management, task-manager), upload the demo files from:
demo-repos/blog-website/index.html
demo-repos/library-management/index.html
demo-repos/task-manager/index.html
For other projects, upload your actual project files.
Step 4:
Test Live Demos
Your live demos will be available at:
https://savangadhiya1.github.io/blog-website
https://savangadhiya1.github.io/library-management
https://savangadhiya1.github.io/task-manager
