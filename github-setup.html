GitHub Setup Guide

Step-by-step guide to make your GitHub repositories live

🚀 Quick Setup for Live Demos

Step 1:
Create GitHub Repository
Go to GitHub.com and create repositories with these exact names:
blog-website
library-management
task-manager
weather-app
inventory-system
sales-prediction
customer-segmentation
sentiment-analysis
Step 2:
Enable GitHub Pages
In each repository:
  1. Go to Settings → Pages
  2. Select "Deploy from a branch"
  3. Choose main branch
  4. Save and wait 2-3 minutes
Step 3:
Upload Your Files
Add your project files to each repository. For web projects, make sure to include:
index.html
style.css
script.js
Step 4:
Test Your Live Demo
Your live demo will be available at:
https://savangadhiya1.github.io/blog-website
https://savangadhiya1.github.io/library-management
https://savangadhiya1.github.io/task-manager
